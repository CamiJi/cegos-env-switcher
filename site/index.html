Extension interne

CEGOS Env Switcher

Passe rapidement d’une URL CEGOS ou CEGOS Integrata en production, preproduction ou localhost, en conservant la route courante.

Télécharger l’extension (.crx) Guide d’installation

Fonctionnalités

  • Switch entre Prod / Preprod / Localhost
  • Compatible avec les domaines CEGOS Integrata
  • Conserve le path, les query params et le hash
  • Badge couleur selon l’environnement
  • Actif uniquement sur l’écosystème CEGOS
  • Clic molette sur Prod / Preprod / Localhost pour ouvrir dans un nouvel onglet
  • Accès direct à la page admin (/wp-admin/) du site courant, quel que soit l'environnement

Exemples supportés

  • https://www.cegos.fr/
  • https://www.cegos-integrata.fr/
  • https://preprodwww.cegos.fr/
  • https://www.cegos.fr.localhost/

Installation initiale (une seule fois)

  1. Télécharger cegos-env-switcher.crx.
  2. Ouvrir chrome://extensions.
  3. Activer le mode développeur.
  4. Glisser-déposer le fichier .crx dans la page puis confirmer l’installation.

Mises à jour automatiques

Après l’installation initiale, Chrome vérifie automatiquement les mises à jour via updates.xml. Vous n’avez rien à réinstaller manuellement.

Vérifier la version installée

  1. Ouvrir chrome://extensions.
  2. Trouver CEGOS Env Switcher.
  3. Comparer la version affichée avec la version ci-dessous.

Dépannage rapide

  • Cliquer sur Mettre à jour dans chrome://extensions.
  • Fermer puis relancer Chrome.
  • Vérifier que les URLs suivantes sont accessibles :
  • updates.xml
  • cegos-env-switcher.crx

Checklist de validation

  • Nouvelle version détectée après bump de la version dans le manifest.
  • updates.xml accessible publiquement.
  • cegos-env-switcher.crx accessible publiquement.
  • Mise à jour fonctionnelle sur un poste test.
